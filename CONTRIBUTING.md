# Contributing to SecondEye

Thank you for your interest in SecondEye.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create and activate a Python virtual environment.
4. Install the dependencies from `requirements.txt`.
5. Make your changes.
6. Run the available tests and verify that the application still works.
7. Create a pull request with a clear description of your changes.

## Development Guidelines

- Keep changes focused and easy to review.
- Follow consistent Python formatting and naming conventions.
- Avoid committing personal biometric data, model weights, virtual environments, or secrets.
- Update the README when adding or changing major functionality.
- Document experimental components clearly.

## Reporting Issues

When reporting a problem, include:

- Operating system
- Python version
- Relevant error message
- Steps to reproduce the issue
- Any relevant configuration details

Please do not include personal face images or biometric data in issues or pull requests.
